# 成员进度：以归档推动任务

目标：老师日常只需发送文字或文件、勾选完成、设置提醒。软件自动留档和总结，减少整理工作。

## 日常交互

- 成员列表保留姓名、年级、自定义 meta 标签，以及一段 bio。初始为空；新增只填姓名即可。
- 首页每人至少 60 像素一行，姓名、年级、meta 标签和当前进展同行；成员信息占可见宽度约 62%，日期占约 38%。点击姓名打开归档、任务、成员信息侧栏，左侧拖动点调整上下顺序。甘特图按日期共用任务排，只有任务时间冲突时增加排数和行高，所有有日期的任务均显示。
- 归档使用类似微信的追加式对话：Enter 发送、Shift+Enter 换行，支持拖入、选择或粘贴文件。历史消息不可编辑；纠正内容通过新消息追加。
- 每次发送先可靠保存本机，再自动生成 GPT 摘要。GPT 摘要也是一条追加消息，并自动更新列表中的当前任务。失败保留原文，提供一次点击重试。
- 摘要里提取的下一步可点击加入任务。在空日期格拖动选择时间范围后，只填写任务名称；已有任务条可移动和调整两端日期。勾选即完成，可撤销；删除任务也提供短时撤销。
- 从具体任务进入归档时，输入文字或放入文件后可“提交并完成”，一次发送同时保存资料和完成该任务。
- 项目只保留名称、成员和共享任务；项目与成员展示同一份任务。项目也使用追加式归档。
- 闹钟支持成员、独立全局及项目三类。点击日期格预填日期，按钮选择常用时刻；全局提醒记忆最近 6 个内容标签。提醒在相关成员的甘特日期背景上标注，项目提醒覆盖当前成员，点击时间可查看内容。成员 meta 记忆最近 8 个标签，点击补入分号分隔的文本框，也可点标签右侧 ＋ 追加。仅使用静音 Windows 通知；关闭窗口后留在托盘，明确退出才停止提醒。
- 成员删除移出活动列表，清理个人任务与提醒，保留其他成员的共享任务及只读历史归档。已使用资料原位保留，更新助手等待旧版正常退出后替换程序。
- 主行当前进展、年级、标签及成员详情字段可原位编辑，历史归档保持追加式。只有右侧甘特图横向滚动，左侧资料固定。
- 年级独立于 meta；带年数的年级每年 9 月自动增加，首次启用以当前填写值为基准，自定义非数字年级原样保留。学年基准由软件内部维护，不增加手填属性。
- 成员行显示其当前项目的小标签，点击进入项目。项目归属从成员列表自动读取，不作为手填 meta。
- 每月提醒保存固定日号和当地钟点，缺日使用月底、随后回到原日号；延后不改变原月度计划。
- 左侧增加独立 GPT 聊天，通过内置 Codex CLI 给建议，也可根据明确的聊天指令创建简单提醒；用本地原子保存和请求去重保证结果一致。支持清空当前会话及一次撤销。默认参考全部提醒和最近归档；归档侧栏可一键引用整个档案，等待用户提问。

## 实现结构

- Windows WebView2 桌面应用，解压目录后直接打开；利用本机已安装的 .NET 8 Desktop 和 WebView2 运行环境。
- 原生宿主负责本地数据、附件、后台定时器及系统通知；界面使用离线 HTML/CSS/JavaScript。
- Data 目录保存状态和复制后的附件，原子写入并保留恢复副本。支持备份导出和恢复。
- 尝试读取本机现有 GPT 接口配置；配置可在设置页修改。密钥仅保存在本机并加密，不进入导出包。
- 自动摘要合并短时间内连续发送，限制上下文长度和输出，避免每条输入重复消耗大量额度。
- GPT 聊天的 UI、持久化、Codex 进程与更新器独立成模块，核心业务通过三个委托提供上下文、连接配置及受限的提醒创建操作。内核内置官方 Windows 版本，设置支持手动更新和可选自动更新。
- 应用、窗口及托盘使用 gpt-image-2 生成的统一 Logo。

## 最小验证

只验证一次构建和核心操作闭环：新增成员、发送文本及附件、自动摘要、任务完成与撤销、共享任务同步、闹钟静音通知和重启后数据恢复。用隔离数据目录运行，不在交付包预置示例成员或密钥。出现问题后仅补测受影响环节。
