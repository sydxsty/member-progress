# 成员进度

双击 **StudentProgress.exe** 打开。第一次使用没有预置成员，不需要账号。

已有便携版时，先完整解压并打开其中的程序。源码构建步骤见 [仓库首页](../README.md)。更新已有应用前，先保存未发送内容并从托盘选择“退出”，保留原 Data 资料目录。

## 平时只做这些

1. **添加成员**：输入姓名即可。meta 标签右侧的 **＋** 可继续追加，最近使用项点击即可填入，也支持分号分隔；年级和 bio 按需补充。
2. **记进展**：点击成员姓名，打开“归档／任务／成员信息”侧栏。像发微信一样输入文字或拖入文件，Enter 发送，Shift+Enter 换行。资料先保存，GPT 随后自动追加摘要并更新首页当前进展。
3. **加任务**：在成员右侧日期区按住拖出起止范围，再写任务名称；任务条可直接拖动改期、拖动两端改起止日期。也可在侧栏写一句话添加，或点击 GPT 的下一步建议。
4. **完成或提交**：任务前的勾选可直接完成，再点一次撤销。任务旁的归档按钮可进入“提交并完成”，一次发送同时保存资料并完成任务。
5. **设提醒**：点击成员右侧的日期格，日期自动带入，点常用时刻即可；顶部“提醒”可选择全局、成员或项目，项目页也有直接添加提醒的入口。全局提醒支持点击最近使用的提醒内容。到点仅发静音 Windows 通知，可以点击打开或延后 10 分钟。
6. **做项目**：取个项目名、选成员，共享任务和项目归档。共享任务在各成员页中同步。

空年级、meta 和进展默认不显示提示文字，鼠标移入或键盘聚焦后显示编辑入口；空进展区域也可以直接点击。姓名旁的年级、meta、当前进展，以及成员详情中的姓名、年级、meta、bio、当前进展都可点击直接修改。Enter 或点击别处保存，Escape 取消；段落里 Shift+Enter 换行。主界面点击姓名仍打开侧栏，历史归档消息可以单条删除并撤销。

日期区域可独立横向滚动，左侧成员和当前进展固定。提醒支持“每月”：选好日期和时刻，例如每月 9 日发劳务费；遇到没有 29/30/31 日的月份会在月底提醒，随后月份回到原来的日期。

当前进展右端汇总该成员相关的全局、个人和项目提醒，显示最近启用时间，点击查看全部相关提醒。

甘特图中，全局提醒标在所有成员对应的日期背景上；成员提醒只标本人；项目提醒标在该项目当前成员的行上。全局提醒采用极浅底色和虚线；同一天每条提醒按时间从上到下显示，点击对应时刻即可查看或修改。已触发的最近一次提醒保留当天标注。

有日期的任务全部显示，日期不冲突的任务共用一排，时间冲突时自动增加排数和该成员的行高。没有日期的任务可在成员侧栏中查看、补充日期。

拖动成员姓名左侧的小拖动点，可以改变成员顺序并自动保存。搜索后也可排序，未显示成员保持原位置。

成员行内以紧凑的小标签显示其参与的项目，点击进入对应项目；项目归属随项目成员设置自动更新，无需再填写 meta。

年级与 meta 标签独立。博一、研二、大三等带年数的年级，每年 9 月 1 日自动增加一级；当前已填年级从启用本功能后的下一次 9 月开始递增，不会在升级应用时重复增加。“本科”等没有年数的自定义内容保持原样。手工改年级后按新值继续计算。

## GPT 聊天

左侧“归档”下面是 **GPT 聊天**。可直接问“今天应优先跟进谁”“接下来先做什么”，默认参考全部提醒和各成员最近归档，也可关闭对应的参考项。

在成员或项目归档侧栏点 **引用整个归档**，即可带着这份记录进入聊天，再输入针对性问题。引用会保留到后续提问，可手动移除；已删除成员的历史也能引用。点击引用不会自动发送。

聊天使用内置的 **Codex CLI**。除了给建议，也可以直接输入“明天9点提醒我核对进展”或“每月9日上午10点提醒我发劳务费”，支持全局、成员或项目的简单提醒。对象或时间不清楚时会追问，可以接着补充；创建成功才显示提醒卡片，点击“查看”可修改。重试不会重复创建同一批提醒。也支持创建日期任务；已有任务、成员资料和归档仍在各自界面修改。

顶部“清空会话”清除当前聊天、草稿和引用；正在回答时会先停止。可立即“撤销清空”，开始新问题后不再恢复旧会话。清空聊天不删除已创建的提醒或历史归档。

问题先保存在本机，回答完成后追加；可以停止、失败后重试。完整引用过大时会明确提示，避免把截短内容当成全文。

设置中的 **GPT 聊天内核** 显示版本，提供检查和更新按钮。自动更新默认关闭；开启后每日空闲时检查，更新失败保留当前版本。便携版无需另外安装 Codex CLI 或 Node；源码构建版首次使用需点击“更新内核”下载聊天组件。

归档和 GPT 摘要通常追加保存；可删除自己发送的某条消息或某条摘要，并在提示中撤销。任务日期、标签和成员补充信息都可以留空，不影响日常使用。

任务列表或任务编辑框可删除任务，提示中提供短时间撤销。成员信息中可删除成员：其个人任务和提醒移出列表，其他成员的共享任务保留；历史归档仍可在“归档”页查看，但不再追加。

## 资料与 GPT

- 资料保存在程序旁的 **Data** 文件夹，附件会复制进去。移动程序时连同 Data 一起移动。
- 设置中的“导出完整备份”保存记录、附件、GPT 聊天历史和独立设置；恢复前会保留当前资料的恢复副本。备份不包含 API 密钥和可重新下载的内核文件。
- 程序会尝试导入本机已有 GPT 接口配置。需要调整时在设置中修改；平时不用重复填写。
- GPT 不可用时，文字和文件仍然保存，点“重试”即可。只有发送归档或明确重试时才调用 GPT，短时间连续发送会合并整理。
- TXT、Markdown、含文字的 PDF、DOCX 可提取文字参与摘要；扫描 PDF、图片和其他不可读取格式保留为附件，界面明确标注。

## 关闭与通知

关闭主窗口后会保留托盘运行，继续提醒。右键托盘图标选“退出”才完全停止；关机期间不提醒，重新运行后处理错过的提醒。

Windows 免打扰或系统通知设置可能隐藏横幅；应用在设置中显示通知可用状态。通知始终静音。

为使通知中心的点击能打开应用，首次运行会在当前用户的开始菜单建立“成员进度”快捷方式，并注册本应用专属通知标识和打开协议，无需管理员权限。移动文件夹后重新打开，会更新当前目录的通知入口。

此版本适用于当前 Windows 电脑，使用已安装的 .NET 8 Desktop 与 Microsoft Edge WebView2；不需要安装开发工具。拷贝到另一台电脑时，该电脑也需要这两个运行环境。

## 开发与核验

源码位于仓库的 `app` 文件夹，设计见 [设计方案](design.md)。GPT 聊天独立放在 `app/Assistant` 与 `app/web/assistant.js`、`assistant.css`，便于后续迭代。构建及离线检查方法见 [仓库首页](../README.md)。

## Android 手机

在设置中的“手机连接”查看地址和设置密码，支持已有 frps 转发。手机成员页左右滑动可查看甘特图，成员、任务、提醒与 GPT 使用电脑现有数据。支持 Android 10 及以上。

手机需允许通知和闹钟权限。后台采用省电同步，电脑新修改的提醒可能在下一次同步后才更新；已缓存提醒在电脑离线时仍可触发。电脑需要保持应用或托盘运行才能远程读写和使用 GPT。

## 当前用户与快速安排

在设置的“当前用户”选中自己的成员记录。GPT 会把“我”和没有另指定对象的安排归到此成员；明确说“全局”或指定其他成员、项目时按指定对象处理。没有选择当前用户时会提示设置，不会改成全局提醒。

- “下午2点叫我”：创建当前用户今天14:00的单次提醒；时刻已过或有歧义时会追问。
- “明天提醒我去南湖”：创建明天的个人任务，不另设一个默认时刻。
- “10月22日-24日提醒我去CNCC”：创建10月22日至24日的个人任务，显示在甘特图。

只说“给出plan”时只给计划；直接要求安排时保存后才显示创建结果。聊天重试不会重复创建，清空会话也不删除已创建的任务和提醒。

提醒列表默认“取消本次”：周期提醒跳过展示的这一次，后续继续按原周期执行。要长期停用，进入编辑页使用单独的整个提醒开关；再次启用也在这里操作。每月31日等月末规则在取消后仍保留。电脑端取消后，手机在下次同步更新；在手机上取消会立即请求同步。

## 甘特图与归档分析

鼠标位于甘特图日期区域时，Ctrl＋滚轮调整每一天的宽度，并保持鼠标所在日期的位置；拖动、调整期限和新建任务继续按当前日期宽度计算。鼠标位于其他区域时，Ctrl＋滚轮维持界面缩放。姓名、年级和 meta 按紧凑列宽对齐，项目标签保留原来的排列。

归档中每条消息都可以删除，包括自己发的文字/附件消息和 GPT 摘要。电脑上鼠标移入或键盘聚焦显示删除按钮，手机上直接点“删除”；短时提示中可撤销。删除会取消该对象正在生成的旧摘要，避免已删除内容再次写入结果。删除一个消息不会级联删除其他消息；可撤销记录与附件随完整备份保留。

Responses 接口的归档分析直接使用原生 Codex。应用提供当前成员或项目的完整历史、任务和原始附件副本，并为常见格式附上便捷文字副本；Codex 自己决定阅读、搜索、看图和解析方法。分析对象不限于论文，也不要求固定的处理步骤。新格式或扫描内容由可用工具尝试处理，无法读取的部分会具体说明。已有原附件无需重新上传，可以重新生成摘要或继续发一条要求。

Codex 只在本次资料副本目录生成派生文件，原始归档保留。使用旧 Chat 接口时仍保留文字摘要兼容路径；自主分析使用 Responses 接口。
