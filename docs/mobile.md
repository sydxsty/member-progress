# 手机连接与使用

Android 10 及以上，版本 1.0.7。Windows 负责保存主数据并运行 GPT，手机使用同一份成员、任务、提醒和聊天记录。

## 第一次连接

1. 打开 Windows 的 **设置 → 手机连接**，开启访问并填写连接密码。
2. 外网连接时展开“外网转发与端口”，填写已有 frps 的服务器、连接端口、业务端口和转发口令。Windows 随程序管理 frpc，无需在本机再运行 frps。
3. 保存后，连接状态显示已连接即可复制地址。该地址后面的 `/mobile/member-progress.apk` 是 Android 安装包入口，电脑版也提供复制安装包地址的按钮。
4. 在 Android 安装 APK，输入电脑显示的连接地址和密码。之后自动记住登录；电脑可修改密码或移除已登录设备。

同一网络可使用设置中显示的本机地址。外网业务端口必须被现有 frps 允许且能够从手机网络访问；它和 frps 的连接端口是两个端口。

连接使用 HTTP。电脑按个人使用要求明文保存密码，不设置登录限速。手机保存设备令牌，不保存电脑连接密码、frp 口令和模型密钥。连接配置位于 `Data/remote`，不包含在完整资料备份或源码仓库中。

## 手机界面

- **成员**：紧凑显示姓名、项目及当前进展。点击进展修改，点击姓名进入归档和任务；左右滑动或点击顶部“甘特图”切换到日期视图。日期在甘特图内部独立滚动。
- **甘特图**：复用 Windows 的任务排布和提醒标注；不重叠任务共用一排，重叠时展开，所有有日期的任务可见。点击任务可修改，点击日期可创建任务或提醒。
- **成员详情**：勾选任务完成、改日期、删除和撤销；发送文字追加归档，也可从任务进入“提交并完成”。摘要由电脑生成。手机不上传或下载归档附件。
- **提醒**：查看和编辑全局、成员、项目提醒，支持 Windows 已有的重复规则，日期和时间使用选择器及快捷项。
- **GPT**：与电脑共用当前会话，引用已有成员或项目归档，支持简单提醒创建、停止、重试、清空与撤销清空。清空会同步影响电脑当前会话，不删除归档和已创建提醒。

图示中的示例并不会预置到应用。没有新增进度百分比、成员属性或其他需要手动维护的业务字段。

## 提醒与离线

允许 Android 通知和“闹钟和提醒”权限后，应用按缓存的计划静音通知。手机只缓存未来 90 天所需的提醒内容、时间、归属和去重标识，联网自动补齐。

打开应用立即同步；后台由系统每 15 分钟申请同步，不保留常驻连接。Android 省电策略可能推迟后台同步，因此电脑刚修改的提醒在下次同步前可能仍按旧安排通知。手机系统也可能限制提醒时机，实际锁屏行为需要在使用的手机上确认。

首次登录忽略过去的历史提醒；后续同步补发上次成功同步后到期、且仍在最近 24 小时内的新提醒。手机重启和覆盖升级后恢复未完成的安排；退出登录清除提醒缓存并取消通知。

电脑需保持应用或托盘运行。电脑离线时，手机可按已有缓存提醒，但无法读取最新进展、保存修改或使用 GPT。当前输入遇到断线会保留并显示未保存，重试同一请求不会重复创建记录。

## 开发接口

`/api/mobile/login` 使用密码换取设备令牌；后续通过 `Authorization: Bearer` 访问。`state` 返回手机字段投影；`assistant` 返回共享会话；`reminder-plan` 返回 Windows 计算的发生时间；`changes` 提供最长 25 秒的变化等待。

写操作通过 `/api/mobile/action`，携带操作、内容、请求标识和已有记录版本。仅开放现有成员进展、任务、文本归档、提醒和聊天操作。电脑与手机同时编辑时返回冲突，不静默覆盖；请求回执与业务修改一同保存。

手机页面位于 `app/web/mobile`，Android 桥接和构建说明见 [Android 模块](../mobile/android/README.md)。Windows 不新增第二个数据服务实例，也不开放设置、备份或本机路径操作给手机。
